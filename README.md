             ✨ What is Findex?

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Findex is a self-hosted search platform that combines
a modern search interface with a dedicated backend and
containerized search infrastructure.

The project is designed around a modular architecture,
allowing search processing, ranking, analytics and
machine-learning capabilities to evolve independently.
